# Flight Checkride Flash Cards

A lightweight browser-based flashcard app for studying common topics that show up on a flight checkride, including regulations, weather, airspace, performance, flight planning, and emergency procedures.

## Features

- Custom study deck with starter questions
- Category filters for focused review
- Flip cards to reveal answers
- Track “I knew it” vs “Need review” progress
- Save cards in local browser storage
- Add your own custom checkride questions

## Run locally

From this folder:

- Open `index.html` directly in a browser, or
- Run `python3 -m http.server 8000` and visit http://localhost:8000

## Files

- `index.html` – UI layout
- `style.css` – visual styling
- `app.js` – flashcard logic and local storage

## Suggestions

Add your own examiner-specific topics, aircraft procedures, and oral question prompts to create a personalized deck before your checkride.
